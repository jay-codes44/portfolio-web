Project 01 — Python · SQLite · Telegram Bot

Bunk-Meter

A Telegram bot that answers the most important question of college life: "Can I skip tomorrow's lecture?" — with math, not vibes.

View on GitHub Next project →

The problem

Every engineering student knows the 11 PM panic: "How many classes have I missed? Can I afford one more bunk?" Doing that math in your head at midnight is how 75% becomes 71%. I wanted a tool that just tells me the answer.

What it does

  • ✓
    Per-subject ledger — log attended / missed lectures with one command.
  • ✓
    Safe-bunks calculator — "you can skip 4 more Data Structures classes" — exact, per subject.
  • ✓
    Daily Telegram digest — every morning: attendance % + today's risk list.
  • ✓
    Red alerts — the moment a subject drops below 75%, it nags you until you show up.

Built with

PythonSQLitepython-telegram-botcron

What I learned

Designing my first database schema (and rewriting it twice), datetime math that doesn't lie, and how a cron job quietly does work while I sleep. Also that users — even roommates — always type commands you never expected.
