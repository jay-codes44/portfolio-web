Project 02 — Python · OpenCV · PyAutoGUI

Dino Runner AI

A bot that plays Chrome's offline dinosaur game by watching the screen — no game API, no hacks. Just pixels in, keypresses out.

View on GitHub Next project →

The problem

My high score was 743 and I refused to grind for it by hand. The real question was more fun: can a program see the game the way I do — just pixels — and react faster than a human?

What it does

  • ✓
    Screen capture loop — grabs the game region ~30 times a second.
  • ✓
    Obstacle detection — scans for dark pixel clusters ahead of the dino, no ML needed.
  • ✓
    Adaptive jumping — distance-based thresholds for cacti vs. flying pterodactyls.
  • ✓
    Personal best: 3,000+ — it stops when I beg it to.

Built with

PythonOpenCVPyAutoGUINumPy

What I learned

That the frame rate of your loop *is* the difficulty of the problem, how image thresholding turns "looking" into simple math, and why sleeping 50 ms too long means a face full of cactus. My first taste of computer vision — and it was delicious.
