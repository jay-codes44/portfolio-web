Project 03 — JavaScript · Chart.js · localStorage

SplitWiser

Expense splitting for hostel roommates: who owes whom, settled with the fewest possible transactions. Zero backend — it all runs in the browser.

View on GitHub Next project →

The problem

Four roommates, one WiFi bill, shared groceries, and a whiteboard full of "I'll pay you later." Keeping track of who owes whom was harder than any assignment — so I made the whiteboard an app.

What it does

  • ✓
    Add expenses fast — split equally or pin custom shares per person.
  • ✓
    Smart settle-up — minimum-transactions algorithm, so A→B→C collapses into one payment.
  • ✓
    Balance charts — who's the group's bank, visualized with Chart.js.
  • ✓
    Works offline — everything saved in localStorage. No server, no accounts, no excuses.

Built with

HTMLCSSJavaScriptChart.jslocalStorage

What I learned

Modeling app state without a framework forces you to actually understand data structures. The min-cash-flow greedy algorithm was the first "real" algorithm I implemented from a paper — and watching four debts become one transaction never gets old.
